粒子シミュレーションを行い、画面出力を描画する、GUIを備えたシミュレーションシステム。
一応コンピュートシェーダーで個別に動かすことはできている。
かなりシンプルな粒子シミュレーション

現在、MPMシミュレーションに変更するため各種追加中。

# プログラムの構成ファイル(ライブラリを除く)
### main,cpp
DEMに近いパーティクルシミュレーター。粒子ベースにて計算している。
計算の本体は以下の[.comp]ファイルにて定義している。
<自力での追加分>
粒子の描画までの流れを流用し、床を表示するようにした。(床は点群にて表示しているので、高さをランダムにすれば山のような地形を作成できるカモ...)

### Window.h
ウィンドウ管理ライブラリのGLEWをラップし、
- ウィンドウ・ライフサイクル管理
- 仮想トラックボール
- GUIの統合
を行っている

### <自力追加> mpmObject.h/.cpp
1つのシミュレーション領域に必要な全リソースをパッケージ化したもの。そのためグリッドにあたる3Dテクスチャと粒子のためのvao/vboを保持している。
粒子のプロパティとグリッドのプロパティを同時に保持している。粒子のものはフィールドとして存在している。

なお3Dテクスチャは、
- 補間を禁止するため GL_TEXTURE_MIN_FILTER / MAG_FILTER を GL_NEARST に設定
- 範囲外アクセス(境界端でのアクセス)時に端の値を固定するため GL_TEXTURE_WRAP_S / T / R を GL_CLAMP_EDGE に設定
している

### shader.h/.cpp
テキストファイルとして存在するシェーダーソースファイルを、プログラムオブジェクトへと変換している。
「頂点+フラグメント」の形式だけでなく、「コンピュートシェーダ」単品でのビルドにも対応している。
またビルド関数の内部にて、ファイルI/Oも入っているので、main側ではシンプルにファイルを渡すだけで良くなっている。

### Object.h/.cpp
シミュレーション領域における粒子の情報を、GPUのビデオメモリ上にて一括管理するための処理を行っている。
SSBO (Shader Storage Buffer Object)としての使用も行うので、速度と位置などを入力している。
現在は粒子物理シミュレーションのため、位置(x)、速度(v)、力(f)を管理していて、プログラムの値の管理もそこで決め打ちしている。
**床面表示のために使用しているのそのまま残しているが、シミュレート用ではなくなったので速度などは不要**

### setup.comp
シミュレーションの最初ステップにて初期化処理を行っている。
力は引き継いでいるとまずいので、こちらだけ初期化して、速度や位置などは引き継いでいる。

### update.comp
シミュレーションの中核ステップ。運動方程式を解いて力を求め、粒子を動かしている。
時間積分の計算と、簡易的な境界条件を実装している。

### collide.comp
DEMに近い計算により衝突判定を行っている。
「全対全」の総当たり探索を行っていて、O(N^2)の計算量である。

### point.vert
取り出した位置をMVP行列を掛け合わせて、画面という2D上の位置に合わせて計算する。
計算している粒子と床面にて計算を変えている。床面の時のみ、シミュレーション中に傾けられるように計算を行っている。

### point.frag
描画するピクセルの色を指定しているだけ。
床と粒子で色を変えている
