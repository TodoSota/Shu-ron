# MPM Simulation using 3D Texture Grid (OpenGL / Compute Shader)

GPU上で動作するMPM（Material Point Method）による土砂シミュレーション。  
従来のグリッド構造を**3Dテクスチャで代替**することで、データアクセスと並列処理の効率化を試みた。

## ■ 概要

MPMは粒子とグリッドを組み合わせた物理シミュレーション手法であり、

- 粒子 → 状態を保持
- グリッド → 力学計算を担当

という役割分担を持つ。

本プロジェクトでは、このグリッド構造を  
**3Dテクスチャとして実装**することで、

- データ転送の簡略化
- 近傍探索の削減
- GPU処理との親和性向上

を実現した。

---

## ■ 特徴

- コンピュートシェーダーによるMPM実装
- グリッドを3Dテクスチャで表現
- P2G / G2P の並列処理
- CASループによる安全なAtomic加算
- GLSL上でのSVD実装
- 塑性変形・硬化モデルの導入

---

## ■ 技術的ポイント

### ● グリッドの3Dテクスチャ化

- 空間座標をそのままインデックスとして利用
- `imageLoad` による直接アクセス
- 探索処理を排除

---

### ● データレイアウトの最適化

- 粒子：std430（高密度）
- グリッド：std140（安全性重視）
- 16バイト境界を意識した構造体設計

---

### ● GPU実装の工夫

- P2Gでの競合をCASループで解決
- SVDをGLSL内で実装
- メモリアクセスの局所性を考慮
