# 
# 概要（Overview）

## ■ プロジェクト全体像

本プロジェクトでは、粒子ベースの物理シミュレーション手法である  
**MPM（Material Point Method）** を用いて、土砂などの粉粒体材料の挙動を再現する  
GPUベースのシミュレーションシステムを実装した。

MPMは、土木分野における地盤解析や土砂災害のシミュレーションなどに用いられる手法であり、

- 粒子（Material Point）：物質の状態を保持
- 格子（Grid）：力や速度の計算を行う空間構造

という2つの要素を組み合わせて計算を行う。

本研究では、この「格子（グリッド）」構造を、  
3DCGで一般的に用いられる**3Dテクスチャ**によって代替し、  

 - ポインタ計算が不要になる
 - 探索がインデックスの直接参照 (O(1)) になる

などMPMの計算をGPU上で効率的に実行することを目的とした。

---

## ■ 何を作ったか

以下の特徴を持つシミュレーションシステムを構築した：

- コンピュートシェーダーによるMPMシミュレーション
- 粒子とグリッドの相互作用（P2G / G2P）の実装
- グリッド構造を3Dテクスチャとして管理
- 土砂挙動（落下・堆積）の可視化

また、MPMの各ステップ：

- P2G（Particle → Grid）
- Grid計算（力・速度更新）
- G2P（Grid → Particle）
- 粒子更新

をすべてGPU上で並列実行する構成とした。

---

## ■ なぜ作ったか

MPMは高精度なシミュレーションが可能である一方、計算コストが高いという課題がある。

特に以下の処理がボトルネックとなる：

- 粒子とグリッド間のデータ転送（P2G / G2P）
- 近傍グリッドの探索処理

従来の実装では、これらの処理において

- 明示的な近傍探索
- 複雑なメモリアクセス

が必要となり、性能低下の要因となる。

そこで本プロジェクトでは、グリッドを3Dテクスチャとして扱うことで：

- テクスチャアクセス（imageLoad）による高速なデータ取得
- 空間構造をインデックスとして直接参照（探索の簡略化）

を実現し、MPMの計算効率の改善を目指した。

---

## ■ 本プロジェクトの特徴（新規性・工夫点）

本プロジェクトの特徴は、**MPMにおけるグリッド構造を3Dテクスチャで置き換えた点**にある。

3Dテクスチャ自体はCG分野において一般的な技術であるが、  
それをMPMの計算グリッドとして直接利用することで、以下の利点を得た：

- グリッドデータをGPUネイティブな形式で管理可能
- メモリアクセスの局所性向上
- 近傍探索処理の簡略化（インデックスアクセス化）

また本実装は、

- CUDAなどの専用計算環境に依存せず
- OpenGL（コンピュートシェーダー）のみで動作

する点も特徴であり、より汎用的なGPU環境での実行を可能にしている。
