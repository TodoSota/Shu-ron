# 実装詳細

## GPU計算パス

C++は1物理ステップごとに次の4パスを起動します。シェーダーは保存方式ごとに `mpm_setup_*`、`mpm_p2g_*`、`mpm_grid_*`、`mpm_g2p_*` に分かれ、線形補間はP2G/G2Pの `_Linear_` 版を使用します。

| パス | 処理 |
|---|---|
| Setup | 格子の質量・運動量をゼロにする。 |
| P2G | 粒子の質量、運動量、APICのアフィン項と応力の力積を周囲の節点に加算する。 |
| Grid | 正の質量を持つ節点で重力、領域境界、床、SDF障害物の接触を処理する。更新速度は運動量の形で格子に戻す。 |
| G2P | 格子速度から粒子速度とアフィン行列を回収し、変形勾配と塑性状態を更新して位置を進める。 |

パス間のメモリバリアで先行パスの書き込みを次のパスから見えるようにします。G2Pは読み取り側の粒子バッファを参照し、書き込み側へ次状態を出力します。正常に完了すると両バッファの役割を交換し、描画も最新の読み取り側を参照します。

## 格子の保存と並列加算

| 方式 | 格子の配置 | P2Gの加算 |
|---|---|---|
| 3Dテクスチャ | 運動量3成分と質量を4枚の `R32UI` 画像に保存。整数の3次元座標でアクセスする。 | `imageAtomicCompSwap` |
| SSBO | 節点あたり4個の `uint`（16バイト）。一辺を (N) とすると `x + N * (y + N * z)` で参照する。 | `atomicCompSwap` |

どちらの `uint` も浮動小数点値のビット表現です。P2Gは読み出した値に浮動小数点加算し、CASで更新します。競合した場合は読み直した値から再計算します。加算順による丸め差があるため、方式比較は許容誤差で評価します。

粒子は `std430` で192バイト、物理パラメータは `std140` で112バイトです。CPU側のサイズと主要オフセットをコンパイル時に検査します。GLSLの定義は [common/](../src/mpm/shaders/common/) に置き、粒子構造体を物理・描画・評価・履歴で共有します。

## 補間・材料・異常停止

2次Bスプラインは各軸3点、線形は各軸2点の節点を使います。線形もAPICの転送を使い、セル内座標を `t` として軸ごとに `dx² × t × (1−t)` を二次モーメントとします。応力散布とアフィン行列の回収では、`t × (1−t)` に1/16の下限を設けた共通の逆行列を用います。節点面の近くでは該当軸の回収が減衰するため、2次Bスプラインとの比較にはこの正則化の影響も含まれます。[線形方式の導出と比較試験](maintenance/stage5-linear.md)

変形勾配のSVDは `FᵀF` のヤコビ法（8巡）を使います。P2GでKirchhoff応力を計算し、G2Pで降伏判定、塑性射影、硬化と体積補正を行います。P2Gの入力とG2Pの試行変形で非有限値、非正の行列式、直交性誤差の超過を検出した場合、直前粒子と試行変形などを保存して計算を止めます。そのステップの粒子出力は採用せず、リセットで停止を解除します。[変形異常の条件と診断形式](maintenance/stage3-validation.md)

## SDFの生成と接触

`MeshResource` は各サンプルで三角形への最短距離と、立体角に基づく巻き数による符号を求めます。入力メッシュの閉曲面、向きの整合、退化などを検査し、起動時は64³の `R32F` テクスチャを生成します。障害物が動くと `SdfInstance` の姿勢と速度を更新し、同じローカルSDFを使います。

Gridパスでは節点を障害物のローカル空間に変換し、テクセル中心を考慮して距離をサンプリングします。勾配をワールド空間に変換して法線を得て、非等方スケール下の距離を局所的に近似します。接触幅 `dx/2` 内では、障害物の並進・回転を含む相対速度から内向き法線成分を除去し、摩擦を適用します。障害物は運動学的に動き、連成は障害物から砂への一方向です。稜線・大曲率・薄い形状ではSDFの近似に制約があります。

## 操作・履歴・評価

`InteractionController` はマウスとカメラからShoot方向やSwing軌道を決め、障害物の状態を更新します。履歴は計算が進んだ描画フレーム単位で記録し、粒子全体をGPUバッファ、障害物のスナップショットをCPU側に保存します。粒子履歴の上限は600フレーム・128 MiB・GPUの単一SSBOブロック上限で決まり、1万粒子では検証環境で69フレームでした。復元対象は粒子と障害物です。

`MpmEvaluator` は設定に応じてGPUパス時間、粒子状態、代表粒子、アプリFPSを収集します。描画・履歴や同期読み戻しの条件は計測結果に影響するため、方式間で性能を比較するときはそれらを揃えます。
