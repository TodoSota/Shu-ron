# 実装詳細

## アプリケーションの起動と再構築

`main.cpp` はウィンドウとOpenGLコンテキスト、ImGuiを初期化し、方式入力、フレームループ、描画、UIを担当します。`SimulationSettings` に方式・補間・粒子数・格子解像度をまとめ、UIの編集中の設定は適用済み設定と別に保持します。

`SimulationSetup.cpp` の `prepareSimulation()` は起動と設定適用で共通です。入力範囲とGPU上限を検査し、方式に応じてシミュレーターを作成して粒子を初期化し、格子解像度に応じた物理パラメータを設定します。作成したシミュレーターと履歴は `SimulationResources` が所有します。設定適用時は候補生成が成功してから `SimulationRun::rebuild()` が現行資源と設定を切り替えます。履歴バッファは利用可能な容量に縮退し、確保できない場合は履歴が無効になります。

`SimulationRun` はmainが保持する資源と操作・描画オブジェクトを参照し、再生状態、コマ送り要求、サブステップ数、FPS記録用の描画フレーム番号を管理します。スコープ終了時にはシミュレーター、履歴、描画資源とImGuiが、ウィンドウのOpenGLコンテキストより先に破棄されます。

## GPU計算パス

C++は1物理ステップごとに次の4パスを起動します。シェーダーは保存方式ごとに `mpm_setup_*`、`mpm_p2g_*`、`mpm_grid_*`、`mpm_g2p_*` に分かれ、線形補間はP2G/G2Pの `_Linear_` 版を使用します。

| パス | 処理 |
|---|---|
| Setup | 格子の質量・運動量をゼロにする。 |
| P2G | 粒子の質量、運動量、APICのアフィン項と応力の力積を周囲の節点に加算する。 |
| Grid | 正の質量を持つ節点で重力、領域境界、床、SDF障害物の接触を処理する。更新速度は運動量の形で格子に戻す。 |
| G2P | 格子速度から粒子速度とアフィン行列を回収し、変形勾配と塑性状態を更新して位置を進める。 |

パス間のメモリバリアで先行パスの書き込みを次のパスから見えるようにします。
ダブルバッファ方式を取っており、G2Pは読み取り側の粒子バッファを参照し、書き込み側へ次状態を出力します。正常に完了すると両バッファの役割を交換し、描画も最新の読み取り側を参照します。

## 格子の保存と並列加算

| 方式 | 格子の配置 | P2Gの加算 |
|---|---|---|
| 3Dテクスチャ | 運動量3成分と質量を4枚の `R32UI` 画像に保存。整数の3次元座標でアクセスする。 | `imageAtomicCompSwap` |
| SSBO | 節点あたり4個の `uint`（16バイト）。一辺を (N) とすると `x + N * (y + N * z)` で参照する。 | `atomicCompSwap` |

どちらの `uint` も浮動小数点値のビット表現です。P2Gは読み出した値に浮動小数点加算し、CASで更新します。競合した場合は読み直した値から再計算します。加算順による丸め差があるため、方式比較は許容誤差で評価します。

粒子は `std430` で192バイト、物理パラメータは `std140` で112バイトです。CPU側のサイズと主要オフセットをコンパイル時に検査します。GLSLの定義は [common/](../src/mpm/shaders/common/) に置き、粒子構造体を物理・描画・評価・履歴で共有します。

## 補間・材料・異常停止

2次Bスプラインは各軸3点(計27点)、線形は各軸2点(計8点)の節点を使います。線形もAPICの転送を使い、セル内座標を `t` として軸ごとに `dx² × t × (1−t)` を二次モーメントとします。応力散布とアフィン行列の回収では、`t × (1−t)` に1/16の下限を設けた共通の逆行列を用います。節点面の近くでは該当軸の回収が減衰するため、2次Bスプラインとの比較にはこの正則化の影響も含まれます。

変形勾配のSVDは `FᵀF` のヤコビ法（8巡）で右特異ベクトル `V` を求め、`F V` の列の長さで左特異ベクトルを正規化します。最小伸び0.01は材料の対数ひずみ計算に適用します。P2GでKirchhoff応力を計算し、G2Pで降伏判定、塑性射影、硬化と体積補正を行います。P2Gの入力とG2Pの試行変形で非有限値、非正の行列式、直交性誤差の超過を検出した場合、直前粒子と試行変形などを保存して計算を止めます。そのステップの粒子出力は採用せず、リセットで停止を解除します。

## SDFの生成と接触

`MeshResource` は各サンプルで三角形への最短距離と、立体角に基づく巻き数による符号を求めます。入力メッシュの閉曲面、向きの整合、退化などを検査し、起動時は64³の `R32F` テクスチャを生成します。障害物が動くと `SdfInstance` の姿勢と速度を更新し、同じローカルSDFを使います。

Gridパスでは節点を障害物のローカル空間に変換し、テクセル中心を考慮して距離をサンプリングします。勾配をワールド空間に変換して法線を得て、非等方スケール下の距離を局所的に近似します。接触幅 `dx/2` 内では、障害物の並進・回転を含む相対速度から内向き法線成分を除去し、摩擦を適用します。障害物は運動学的に動き、連成は障害物から砂への一方向です。稜線・大曲率・薄い形状ではSDFの近似に制約があります。

Gridは床・格子端の速度拘束を先に適用し、SDF接触で速度が変わった節点に同じ拘束を再適用します。傾斜床では格子端の外向き速度を復活させない方向に、残った床向き成分を補正します。同時接触で両方の要求が競合するときは静的境界を優先します。

## 操作・履歴・評価

`InteractionController` はマウスとカメラからShoot方向やSwing軌道を決めます。Swing中は解析式から姿勢と速度を同じ時刻に求めます。一時停止中も操作を準備でき、物理時間は再生またはコマ送りで進みます。ShootとRepeatは床や格子端に当たるまで発射速度を保って直進します。初回の衝突を処理した次の物理ステップから重力を適用します。床接触は実メッシュ頂点の床法線方向の最下点を使います。反発係数は0.25とし、衝突速度が0.25 m/s未満なら法線方向の反発を省略します。接線方向は床摩擦で減速します。床下からの発射は実メッシュが床面を抜けた時点で床接触を有効にし、格子端では外向きの軸成分を止めます。Shootの進行と片面接触の状態は障害物の姿勢とともに履歴から復元されます。[ShootとC-9の再調整](maintenance/shoot-bounce-validation.md)

`SimulationRun::advance()` は障害物と操作状態をサブステップ前に保存し、C-9で停止した場合はその状態へ戻します。粉塵は完了した物理時間分だけ進みます。通常再起動は現在のシミュレーターで粒子を初期化し、設定適用による再起動は新しいシミュレーターを使います。どちらも障害物・履歴・物理時計を初期化し、直前操作の再実行情報を保持します。

`SimulationRun` が記録と復元のタイミングを制御し、`TimelineManager` は初期状態と、物理計算が進んだ各描画フレームを保存します。粒子全体はGPUバッファに置き、障害物、操作コントローラー、物理設定、完了ステップ数、累積物理時間はCPU側に保存します。復元時に粉塵を消去し、途中のマウスドラッグを解除します。巻き戻し後に再生またはコマ送りを開始すると、その位置より後の履歴とステップ計測を切り詰めます。粒子履歴の上限は600フレーム・128 MiB・GPUの単一SSBOブロック上限で決まり、1万粒子では検証環境で69フレームでした。

`MpmEvaluator` は設定に応じてGPUパス時間、粒子状態、代表粒子、アプリFPSを収集します。GPUパス時間と状態集計の記録には、それぞれ計測と読み戻しを有効にします。代表粒子とFPSは独立して記録できます。粒子状態の領域外は `[0, worldScale]³` の外にある有限位置です。CSVの状態・代表粒子欄は未取得時に空欄になります。ステップログに累積物理時間、刻み、床設定を記録し、FPSログは一時停止中も描画フレーム単位で記録します。ログ消去はカウンターを維持し、再起動はログとカウンターを初期化します。描画・履歴や同期読み戻しの条件は計測結果に影響するため、方式間で性能を比較するときはそれらを揃えます。物理タイマーは成功ステップで同期回収し、描画の `PassTimer` は準備済みのクエリを遅延回収します。[工程9の検証と計測設計](maintenance/stage9-validation.md)
