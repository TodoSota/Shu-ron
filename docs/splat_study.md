# 土砂の描画手法の再検討：格子による表面粒子の抽出とスプラッティング

2026-10-30（Claude Doc「[土砂の描画手法の再検討：格子による表面粒子の抽出とスプラッティング](https://claude.ai/artifact/XHhMr6LfpgrLrVXeZsFCU3)」の写し。実装の手順は [splat_guide.md](splat_guide.md) を参照）

## 背景: 今の方法が土砂に合わない理由

現在の Surface モード（球インポスタの深度をスクリーン空間で平滑化して面を張る方法）は、土砂には次の 3 点で合いません。

- **視点に依存する。** 平滑化の範囲が画面上の画素で決まるため、カメラを動かすと面の形が変わり、斜めから見たときの波打ちやちらつきの原因になる。
- **流体向きの処理である。** 元々は水の表面を滑らかに見せるための手法で、土砂のざらついた、境界のあいまいな見え方とは逆の方向に働く。
- **球の陰影が目立つ。** 球の法線による拡散反射の濃淡が粒子ごとに出るため、粒子の集まりではなく「球の集まり」に見えてしまう。

土砂の表面は連続した 1 枚の面ではなく、表面付近の粒子群がぼんやりと作る層です。そこで、面をはっきり抽出するのではなく、物体空間で表面粒子と法線を求め、半透明のカーネルで重ねて描く方法を検討します。

## 表面粒子の抽出と法線

描画専用の粗い格子に粒子の密度を集め、そこから表面の判定と法線を求めます。近傍探索は不要で、粒子ごとの atomic 加算と格子の参照だけで済みます。

### 描画用の格子

- セルの大きさは粒子間隔の 1〜2 倍とする。MPM の格子 (gridIMA, 128³) はセルあたり約 0.6 個と疎すぎるため、別に用意する。
- 各セルには粒子の個数（密度 ρ）だけを atomic に加算する。粒子を最寄りの 1 セルではなく周囲 8 セルへ三線形の重みで配ると、勾配が滑らかになる。

### 表面の判定

- 隣接セルに空のセルがある粒子、または |∇ρ| が ρ に対して大きい粒子を表面粒子とする。
- 内部の粒子は描かない（陰影にも影にも寄与しない）。

### 法線の求め方

- **(a) 密度勾配（採用）:** n = −∇ρ / |∇ρ|。格子の中心差分で求め、格子をぼかす半径で滑らかさを調整する。
- **(b) 主成分分析 (PCA)（不採用）:** 周囲のセルのモーメントから共分散行列を作り、最小固有値の固有ベクトルを法線とする。より正確だが、1 セル 10 成分の加算と粒子ごとの 3×3 固有値分解が要る。

```latex
\mathbf{n} = -\frac{\nabla\rho}{|\nabla\rho|},\qquad (\nabla\rho)_x \approx \frac{\rho_{i+1,j,k}-\rho_{i-1,j,k}}{2h}
```

### (a) を採用する理由

精密さよりも、見かけとその制御のしやすさ、および速度を重視するためです。

- **見かけを制御しやすい:** 格子をぼかす半径という 1 つの値で、法線の滑らかさを連続的に変えられる。PCA にも近傍の大きさという調整値はあるが、密度勾配は線形のぼかしをかけた場の微分なので、調整値に対して法線が素直に変わる。
- **法線が飛ばない:** PCA では、最小と 2 番目の固有値が近い場所（角・崩れかけ・まばらな所）で固有ベクトルが入れ替わり、法線が急に向きを変えることがある。密度勾配はそうした場所でも連続に変わり、勾配の大きさが小さくなるだけなので、大きさを法線の信頼度として使える。
- **外向きが決まっている:** PCA の法線は n と −n を区別できず、外向きを決めるには結局、密度の低い側（∇ρ）を見る必要がある。密度勾配では向きは初めから決まっている。
- **速い:** 1 セル 1 個の float の加算と中心差分だけで済む。PCA は 1 セル 10 個の atomic 加算と、粒子ごとに周囲のセルのモーメントを集める処理が要る（3×3 の固有値分解そのものは軽い）。差が大きくなるのは粒子数を増やしたときである。
- **土砂には鋭い形の精度が要らない:** ぼかした密度の勾配は、SPH の color field やメタボールなど、粒子の表面の法線として広く使われ、滑らかな面では十分に正確である。PCA が勝るのは鋭い稜線や角を残したい場合で、土砂ではそれはかえって不要である。また半透明のカーネルを重ねて描くので、法線の細かな誤差は画像に表れにくい。

PCA を使わないので surface variation σ は得られません。代わりに、ρ の小ささ（まばらさ）や |∇ρ| / ρ（境界のはっきりさ）を、陰影をあいまいにする指標に使います。

## 半透明カーネルによる描画

表面粒子を、法線の向きに向けた円盤（surfel）として、ガウス関数で縁に向かって薄くなる重みを付けて描きます。半径は粒子間隔の 1.5〜2 倍とし、隣り合う円盤が重なってすき間を埋めます。

### Deferred splatting の 3 パス (Botsch et al. 2005)

1. **可視性パス:** 円盤を深度だけ描く。奥へ少しずらした深度を書き、手前の表面の厚みを決める。
2. **蓄積パス:** その厚みの中にある円盤の、重み × 色・法線を加算ブレンドで足し合わせ、重みの和 Σw も記録する。
3. **正規化パス:** Σw で割って画素ごとの色と法線を求め、既存の G-buffer に書き込む。以降の陰影・影・AO・粉塵は今のパイプラインをそのまま使う。

### 被覆率による輪郭の半透明化

Σw はその画素がどれだけ粒子に覆われているかを表すので、不透明度に変換して輪郭やまばらな所をぼかします。k はどれだけ速く不透明になるかを決める調整値です。

```latex
\alpha = 1 - \exp\left(-k \sum_i w_i\right)
```

## 陰影の付け方

土砂らしい「あいまいな陰影」は、拡散反射を柔らかくし、影を体積的に求め、細かい凹凸を色で表すことで作ります。

- **拡散反射:** wrapped Lambert（(n·l + a)/(1 + a) で影の境界を広げる）か、粗い面用の Oren–Nayar を使う。密度の低い（まばらな）所ほど a を大きくすることもできる。
- **柔らかい影（任意）:** 密度格子を光源方向にレイマーチして透過率を求める。表面のすぐ下が少し暗くなり、薄い所は光が透ける。今のシャドウマップと置き換えるか、併用する。
- **ざらつき:** 法線は滑らかなままにし、粒子ごとの明るさのばらつき（albedo）で粒状感を出す。球の法線は使わないので、球が見える問題は起きない。

## 期待できる効果とリスク

法線と表面の判定を物体空間で求めるため、視点を動かしても見え方が変わらず、フレーム間でも安定することが主な効果です。

| 項目 | 内容 | 対策 |
| --- | --- | --- |
| 効果: 視点に依存しない | 斜めから見た波打ち・ちらつきが原理的に起きない | — |
| 効果: 球が見えない | 粒子ごとの陰影の濃淡がなくなる | — |
| 効果: 輪郭があいまい | 被覆率で縁やまばらな所が半透明になる | — |
| リスク: 粒子が疎 | 粒子数が少ないと法線が乱れ、穴が開く | 格子を粗くする、円盤を大きくする |
| リスク: 薄い膜 | 薄く広がった砂では表裏の区別が付かない | シミュレーションの問題 A-2（C×dx）・A-3（粒子体積）の修正が前提になる可能性 |
| リスク: 計算量 | 格子への atomic 加算と 3 パスの描画が増える | PassTimer で計測して判断 |

## 進め方の案

新しい描画モード「Splat」を既存の Points / Spheres / Surface に並べて追加し、4 段階で進めます。各段階の終わりで結果を確認してから次へ進みます。

1. **格子と法線:** 密度格子、表面の判定、密度勾配による法線を実装し、表面粒子・法線・密度を色で見るデバッグ表示を付ける。
2. **Deferred splatting:** 3 パスの描画を Splat モードとして追加し、G-buffer に書き込んで既存の陰影・影・AO とつなぐ。
3. **あいまいさ:** 被覆率による半透明化と、wrapped Lambert / Oren–Nayar による柔らかい拡散反射を入れる。
4. **密度格子の影（任意）:** レイマーチによる柔らかい影を試し、シャドウマップと見比べる。

**実装の状況（2026-10-30）**: 4 段階すべてを実装した。低い角度から見たときのちらつきの指標は、段階 4 で Surface モードより良くなった（隣り合うフレームの明るさの差 1.86、Surface モード 2.13）。実装中に計画から変えた点と計測の詳細は [splat_guide.md](splat_guide.md) と [splat_implementation.md](splat_implementation.md) を参照。
