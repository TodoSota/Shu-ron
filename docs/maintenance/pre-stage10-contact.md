# 工程10前の同時接触対応（B-5／B-6／C-9）

当時の移動制限案と検証の記録。現行のShootの挙動とSVD変更は[再調整の記録](shoot-bounce-validation.md)を参照。

## 停止の再現

利用者は工程9の操作感の維持を確認し、領域外へ押すShootで停止を報告した。`C9-17950879937971083-0` は完了3408ステップ、G2Pの試行変形、粒子5251、reason 3。直交性誤差は0.04626、行列式は0.01106、保存行列のCPU参照最小特異値は約0.00959。前状態の粒子は `(0.85476, 0.09294, -0.01031) m` にあり、床下と格子外の両方に該当した。全粒子では領域外31個、床下1227個。

Intel UHD、元の粒子と物理UBO、保存された障害物の姿勢・速度、本体の生成器で作った実OBJの64³ SDFを使い、旧Gridで同じステップ・粒子・理由の停止を再現した。Gridの拘束を再適用すると次の1ステップを完了した。すでに領域外にある31粒子はそのまま残った。

## 採用した対策

1. TEX／SSBOのGridで、移動SDFの接触応答後に床・格子端の静的速度拘束を再適用する。傾斜床と端が競合する場合は、外向きの格子速度を生まない方向で残る床向き成分を補正する。床・格子端と障害物の拘束が同時に満たせない場合は静的境界を優先する。
2. ShootとRepeatでは、余白付きSDF AABBと床・領域端の間に3格子間隔を残すよう、移動の割合を制限する。最後の部分ステップのSDF応答には実際の変位に対応する速度を渡す。余白を越えた位置からはさらに近づく移動を止め、離れる移動を許す。Shootの軌道が境界手前で短くなる。SwingにはGrid側の対策が適用される。

この対策は領域外への押し出しと、運動学的な障害物が境界と重なって砂を圧縮する経路を抑える。C-9の診断と閾値を維持する。

## 比較結果

基準dt 0.25 ms、128³格子、Intel(R) UHD Graphics / OpenGL 4.3.0 / 32.0.101.7082。実OBJ、同じ初期粒子パッチ、障害物の発射方向と速度を使用。領域外は `[0,1.5]³` の外にある粒子中心、侵入深さは粒子中心でサンプルした実SDFの負距離とする。描画、評価、履歴を外して4物理パスを試験した。

| 条件 | 結果 |
|---|---|
| 境界近傍で障害物が床の余白内にある初期条件、旧実装 | 4方式で125〜128ステップ後にC-9停止。領域外は最大85〜87個。 |
| 同じ初期条件、Gridの再適用だけ | 領域外0。2次Bスプラインは140ステップを完了。線形は2方式とも122ステップでC-9停止。最大SDF侵入は39.4〜58.2 mmで、旧実装の10.6〜21.4 mmより増加した。 |
| 同じ初期条件、C++の移動制限とGrid再適用 | 4方式が180ステップを完了。領域外0、粒子中心の床下0、最大SDF侵入6.47 mm。障害物が開始時点から床へ近づく制限に当たる条件。 |
| 床の余白を取った別の開始位置 | 新旧とも4方式で180ステップを完了。旧実装で最大2.16 mmの床侵入、新実装で0。制限付きの軌道でも粒子の最大速度は4.84〜4.90 m/sに達した。 |
| 領域内部の対照 | Grid変更前後の140ステップを4方式とも完了。終端の位置RMS差は最大7.51 µm、速度RMS差は最大0.54 mm/s。 |
| 静的境界の既存試験 | SDFなしの床・面・角をTEX／SSBOで各18条件。全条件合格、GLエラー0。 |

Debug x64とRelease x64の隔離ビルドを作成した。Releaseは隔離ビルドのPDBリンクエラーをデバッグ情報なしの再リンクで回避した。Release本体でTEX／SSBOの2次Bスプラインを起動し、シェーダー読み込みと正常終了を確認した。

新実装の連続試験は本体と同じC++の移動制限関数で得た姿勢・速度を、実GPUの4パスへ渡した。手動Shootの全軌道、強いSwingでの複合接触、別GPU・長時間は未確認。領域外へ出た既存状態を補正する処理やSVDの精度対策は別課題。まず新規状態から同じ手動ShootとRepeatを試し、停止した場合は新しいC-9診断で再評価する。
