# Shootの床反発とC-9の再調整

この節は飛行中にも重力を適用していた版の記録。現在の直進条件は末尾を参照。

## 変更

ShootとRepeatを重力、片面床接触、反発、摩擦で更新する。床は実メッシュ頂点の床法線方向の最下点で判定する。床下の発射はメッシュ全体が床を抜けてから床接触を有効にする。反発係数は0.25、反発を打ち切る衝突速度は0.25 m/s。接線方向は床摩擦係数で減衰する。格子端では外向き移動成分を止める。Gridの静的境界の再適用は維持した。

SVDでは右特異ベクトルを従来どおり求め、左特異ベクトルを `F V` の列の長さで正規化する。伸びの下限0.01はP2GとG2Pの対数ひずみへ移した。C-9の停止条件は維持した。

## 検証

- C++の軌道プローブで実OBJを使い、浅い衝突後の約44 mmの水平移動、下からの発射で約18.75 ms後に床接触が有効になること、壁に沿う移動、静止時の反発抑制を確認した。各3000ステップ、dt 0.25 ms。
- Intel UHDの実GPUで保存行列の直交性誤差は0.0462582から4.93e-5になり、相対再構成誤差は5.54e-7。保存粒子群から次の1ステップを完了した時点で、もとから領域外にいた31粒子は残った。
- 実OBJとC++の軌道を渡した短時間試験では、TEX／SSBOと2次Bスプライン／線形の全4方式が300ステップを完了した。粒子の領域外流出は0、SDFへの粒子中心の侵入は0、床下への入り込みは最大4.36 mm。格子128³、dt 0.25 ms、描画・履歴・評価を省いた固定入力。
- 既存の線形GPU回帰は各10判定に合格。2次BスプラインのSVD・応力・転送等の各82判定に不合格はなかった。初期化プローブは現行main.cppとハッシュが一致せず実行前に拒否されたため、初期化を含む回帰全体は保留。

Debug x64の隔離ビルドに成功した。ビルドログは `artifacts/baselines/bounce-debug-resumed.log`。

証跡は `artifacts/baselines/bounce-svd/`、`bounce-gpu/`、`bounce-reg-*/`、`contact-replay-pre10/bounce-host/`。傾斜床と端の連続接触、実マウスでの繰り返し操作、別GPUと長時間運転は未確認。反発と摩擦の見え方は操作確認に基づく調整を残す。


## 初回衝突までの等速直進

クリックによる照準を保つため、ShootとRepeatは床または格子端に当たるまで発射速度で進む。初回衝突の次の物理ステップから重力を加える。接触済みの状態はコントローラーとともに履歴に保存され、再発射で初期化される。床下から上へ抜ける動きは床への衝突として扱わない。

C++プローブで水平発射が200ステップ後も高度と速度を維持すること、格子端で出向く速度を止めた後に落下すること、床で反発して横に滑ること、床下から上へ抜けても直進を継続することを確認した。新しい軌道と実OBJを使ったIntel UHD試験では、格子128³、dt 0.25 msで全4方式が300ステップを完了した。領域外への流出とGLエラーは0。砂の床下への入り込みは最大約3.16 mm。証跡は `artifacts/baselines/contact-replay-pre10/straight-host/trace.log` と `artifacts/baselines/straight-gpu/report.json`。実マウスでの操作感は未確認。

Debug x64の隔離ビルドも成功した。ログは `artifacts/baselines/straight-debug.log`。


利用者が実画面でShootの操作感に問題がないことを確認した。以前停止したように粒子を領域外へ向けて押した操作でも稼働が続いたとの報告。試行回数・操作条件・領域外粒子数は未計測。
