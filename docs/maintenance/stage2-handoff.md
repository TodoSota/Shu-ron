## 工程2で進める順序

以下は実施予定。詳細な試験時間・数値許容誤差は各試験の実行前に決めて記録し、結果に合わせて緩めない。

| 順序 | 作業 | 確認・記録する内容 |
|---|---|---|
| 1 | 現状保存と工程1の回帰確認 | 利用者差分、入力/ツールのハッシュ、現在の基準値。既存ログは上書きしない |
| 2 | 4パスの接続確認 | Setup → P2G → Grid → G2P、UBO/image/SSBOの接続、バリア、出力バッファ交換、直接読戻し |
| 3 | 短時間の既知解試験 | 重力なし/衝突なしの定数移流、衝突前の重力下運動。応力と時間積分の影響を切り分ける |
| 4 | 床・6面・角の境界試験B-5/C-3 | 外向き/内向き速度、摩擦、床の判定位置、粒子支持域が領域外へ出るか、高速接近 |
| 5 | 同一物理時間でdt比較B-1 | dt=0.001、0.0005、0.00025。位置、速度、AABB、有限性、detF、最初の異常発生時刻 |
| 6 | 落下・堆積と配置密度の確認A-3 | 既定条件を先に保存。粒子/セル、質量・領域逸脱、最大速度、堆積形状。密度を変更した比較は別条件 |
| 7 | 必要な修正と回帰、資料更新 | 修正前後を分けて再試験。対象コメント・台帳・PLANSを更新し、制約を付けて基準方式の可否を判定 |

dt比較は計算上の同じ時刻で行う。例: 0.1秒までなら100/200/400ステップ。
この0.1秒は手順説明の例であり、堆積試験の十分な試験時間を定めたものではない。
subStepsを増やすだけではdtは小さくならない。
現在値で発散した場合も結果を残し、原因を切り分ける前にEや密度を調整しない。

Gridの現コードでは下端が `coords < 3`、上端が `coords > size - 3` であり、対象節点数が対称ではない。
この非対称性と2次Bスプラインの支持域の関係を調べる。静的に見える差を、そのまま実害が検証済みと扱わない。
工程1のGL_ALL_BARRIER_BITSによる分離試験だけで、本体のバリア配置が検証済みとも扱わない。
