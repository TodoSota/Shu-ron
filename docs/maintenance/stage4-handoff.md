## 維持する基準条件と採用判断

- 領域[0,1.5]³、格子128³、初期立方体10,000粒子、seed=0、中心(.75,.75,.75)、一辺.3。
- E=50000、ν=.3、密度400、総体積.027、総質量10.8、dt=.00025、subSteps=1。
  平均.596粒子/セルを勝手に増やさない。subStepsを増やしてもdtは小さくならない。
- 床y=.1、摩擦.6、SDF接触幅dx/2。粒子の描画半径とは区別する。
- SVDは現行Jacobi8巡。通常の3巡で直交性基準を超える入力を再現済み。
  8巡は最小・最適と証明した値ではなく、基準の精度を満たす暫定値。
- C-9はP2G入力/G2P射影前の非有限・非正det・U/V直交性誤差>5e-4を診断して停止。
  失敗したステップをswap/stepCount/評価/履歴へ採用せず、resetまで停止を維持する。
  反転後の物理継続・新しい正則化・状態保持による継続は採用しない。
- SDFは入力検査付き巻き数符号、距離の絶対値は三角形への最短距離。
  参照は勾配による局所世界距離近似。稜線・境界・大曲率で厳密な距離/法線を保証しない。
  ゼロ/無効勾配でのSDF応答省略と、一方向連成を維持する。
- 球配置は半径=worldScale*.1*scale、体積=(4π/3)R³/N、質量=体積×呼出し元指定密度。
  共通reset/setPhysicsの順序とcubeへの切替を尊重。既存UIの生成はcube。

## 開始時に確認したSSBO側の差分

以下は静的確認であり、SSBOの実行試験結果ではない。修正時は改めて呼出し関係・式を確認する。

| 対象 | SSBOの現状 | 基準へ揃える内容 |
|---|---|---|
| SVD（A-1/C-9） | Jacobi3巡、回転角は正符号。診断SSBO・停止処理なし | 回転行列の置き方を含めて負符号/8巡へ。診断と非swap・保存・reset復帰をCPU/GPU両側へ展開 |
| G2PのC（A-2） | ワールドdposに `4*inv_dx` | 2次Bスプラインの `4*inv_dx*inv_dx`。Linearへ機械的に適用しない |
| 応力（B-2） | `U*stress_diag*V^T` にF^Tを追加 | 基準のKirchhoff応力 `U*stress_diag*U^T`、追加F^Tなし |
| 硬化/塑性（B-3/B-7） | h3=3、せん断ノルム小のときも引張側の分岐 | h3=10、引張をtr_e>0で先に判定し、等方圧縮を弾性判定へ進める |
| 小質量節点（A-2/B-1） | Grid/G2Pで1e-7の絶対閾値 | 正の小質量を保持し、空節点だけ除外 |
| 床/領域境界（B-5） | 節点位置に半セル加算、床で反発係数を使用。基準の上下各3節点拘束なし | 節点位置coords*dx、侵入法線速度を除去。上端size-3を含め上下各3節点 |
| SDF（B-6） | UVW中心補正なし、距離はx軸倍率、法線のAABB/解像度補正なし | 基準の座標対応・勾配補正・距離近似・ゼロ勾配ガードを展開。逆転置自体は既に存在 |
| G2Pの位置書込み | writeonlyのParticleOutに `position.xyz += ...` | 入力位置を明示的に読んで代入。最初の全粒子コピーがあってもwriteonly出力の読出しに依存しない |

各シェーダーのUBO宣言は使用中フィールドのオフセットを確認する。末尾の未使用宣言がないことだけで
レイアウト破損と判断しない。粒子192バイト/物理UBO112バイトと描画・評価・履歴の共有を維持する。

## 保存方式に固有の接続確認

- 粒子入力/出力はSSBO binding=0/1、物理UBOはUBO binding=1。名前空間は別。
- 格子はSSBO binding=2、`GridNode={uint x,y,z,m}`、std430で1節点16バイト。
  uintは整数の質量値ではなく、浮動小数点のビット表現。試験の読戻しもビット再解釈する。
- 添字は `x+N*(y+N*z)`（xが最も速く変化）。CPU配列のz/y/x順と合わせる。
  128³の格子は32 MiB。GPUのSSBOサイズ・binding上限も実環境で確認する。
- Setup/Gridは8³スレッド、P2G/G2Pは64スレッド。u_gridSizeは4プログラム全てへ設定する。
- 格子のCASはバッファ用atomicCompSwap。TEXのimageAtomicCompSwapをそのまま置換しない。
- 各パス間はSHADER_STORAGEバリア、最終粒子出力はVERTEX_ATTRIBも必要。
  CPU読戻し時のBUFFER_UPDATEバリアと、診断binding=6の再接続を確認する。
- C-9の現行診断レイアウトは96バイト。GPU検知だけでなくホストのラッチ・保存・非swapが必要。
  共通のsimulationErrorとmainの障害物/controller復元は存在する。Linearを意図せず検査有効にしない。

## 作業・試験の順序

1. 現在の差分・入力・ツールを新しい出力先へ保存し、TEX基準回帰と停止/保存を再確認。
2. SSBOの接続・ゼロ初期化・全シェーダーコンパイル・格子レイアウトを確認する。
3. SVD/応力/塑性/C回収と、格子アクセスの差を識別できる変更単位で実装・試験する。
4. 定数/アフィン/回転の転送、質量/運動量、境界、接触と実生成SDFを独立参照で確認する。
5. C-9のP2G異常とG2P試行異常で、診断内容・入力保持・停止・保存・reset復帰を実本体でも確認する。
6. 同じ初期粒子をTEX/SSBOへ複製し、1ステップと連続計算の比較を行う。
   立方体/球の1秒落下・堆積、実生成障害物の静止/並進/回転から始め、採用したSwing比率も確認する。
7. Debug/Release x64を隔離ビルドし、基準TEXに回帰がないことも確認。台帳・コメント・進捗を更新する。

既存toolsは主にTEX専用。PipelineのテクスチャをSSBOへ置き換えただけで試験が成立するとは扱わない。
格子のbuffer readback、u_gridSize、バリア、C-9のCPU側まで方式に対応させる。

既存の独立試験閾値はSVD/応力5e-4、転送3e-5、質量3e-6、初期化2e-6。
1秒の刻み比較は位置RMS .02m・重心.01m・AABB .03m。これらはそれぞれの試験の閾値であり、
TEX/SSBOの方式間比較の許容誤差へ無条件に流用しない。方式間の初期条件・実行時間・測定量・
尺度・許容誤差を、実行前に別の試験計画へ固定する。加算順の違いにビット一致を要求しない。

## 利用者との確認から持ち越す事項

- 利用者は閉曲面・向き整合・自己交差のないモデルを用意する方針。開いたメッシュの対応拡張は要求していない。
- 凹部の空中停止は利用者の過去の観察。旧符号誤りで説明できる候補だが、実モデルで原因を確定したわけではない。
- 薄壁/狭い空隙は有限解像度のSDF補間でも失われる。閉曲面を用意すれば全て解決するとは扱わない。
- 巻き数生成の事前時間の具体計測は利用者が不要と明示。工程4で追加の事前時間計測を必須にしない。
- Jacobi8巡単独のGPU時間差は追加測定で小さかったが、本体の許容FPSは未確定。
  同期込みのPython測定器は対照より約22〜23%増。本体FPS低下率とは同一視しない。
- 工程4ではまず同じ停止検査条件で方式を比較する。検査頻度低下、3巡へ戻すこと、CAS最適化、
  dt/材料/配置密度変更を比較の途中へ混ぜない。収束時終了・同期削減は未実装の別検討。
- 主画面の全操作・描画/評価/履歴との統合、長時間、高速条件は未検証。工程3完了をその保証へ拡張しない。
