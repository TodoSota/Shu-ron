## 現時点で確認している不具合・制約

| ID | 確認した内容 | 工程3で混同しないこと |
|---|---|---|
| C-2 | distは[-1,1]なのにv=dist*2-1、w=dist。工程1で10,000中4,999粒子が非有限 | 非有限性の修正と、球半径・球体積・密度・配置領域の変更は別問題 |
| C-9 | 特異値下限.01のSVDでU=FVΣ^-1。クランプ例の直交性誤差.577、反転例のdetU=-1 | 再構成できる/NaNがないだけで、適切なSVD・構成則とは判定しない |
| B-6a | TEXの距離はローカルSDF×平均スケール。Swingは(.06,.4,.06) | 平均スケールは非等方変換後の厳密な距離ではない |
| B-6b/c | テクセル中心補正・AABB幅の法線補正・逆転置変換は既に存在 | 修正済み実行文を重ねて適用しない。非立方AABB・実生成SDFは未検証 |
| B-6d | 生成位置はsdfMin+idx*cellSize、cellSize=幅/(res-1)。符号は最近接三角形の面法線 | 辺・頂点・凹形状・退化面の符号が正しいとは未確認。生成後AABBはpadding込みに更新される |
| B-6e | 障害物は速度・角速度による運動学的更新 | 砂からの反力を追加する双方向連成は今回の整備とは別の研究選択 |

現在の球半径は `r=cbrt(w)*scale` で、立方体の `worldScale*.1*scale` と異なる。
scale=1なら球半径は最大約1であり、中心.75の領域へ必ず収まるとは限らない。
乱数を有限に直しただけで球の領域逸脱まで解決したと扱わない。
球の体積に応じた質量の扱いも、立方体基準の既存条件との比較を準備して判断する。

## 着手手順と試験の組み立て方

各試験の前に、独立した期待値、許容誤差、入力、時間、打切り条件を保存する。
SDFの補間誤差はボクセル幅と位置に依存する。工程2の速度閾値を距離誤差へそのまま流用しない。
CPU生成・GPUサンプリング・接触速度更新を分離してからつなぐ。

| 順序 | 作業 | 判定・記録する内容 |
|---|---|---|
| 1 | 工程1回帰と工程2基準の再確認 | 92判定の正常系と既知失敗を区別。旧dt=.001の比較不合格は消さない |
| 2 | C-2の再現と最小修正 | 球内一様分布の独立期待値、半径上限、各軸平均、半径分布、有限性、seed再現性、両バッファを確認。立方体も回帰 |
| 3 | C-9の入力別診断 | 正det、近特異、ゼロ、反転、繰返し特異値、回転付き入力。再構成・直交性・特異値・det・材料出力を別々に確認 |
| 4 | B-6c/bの座標と法線 | 合成平面/球/箱、非立方AABB、等方スケール、回転。解析的な距離・法線に対しCPU生成値とGPU読戻しを比較 |
| 5 | B-6aの近似評価 | 非等方平面・箱等の独立した世界座標の距離/法線と比較。Swing比率を含め、接触領域・厚さの誤差を測る |
| 6 | B-6dの符号と退化面 | 閉じた凸/凹メッシュの内外、面/辺/頂点付近、向き違い、面積0、開いたメッシュ。対応入力と非対応入力を明示 |
| 7 | 候補の比較と採用 | 下記の判断事項について、誤差・実装影響・研究上の意味を示して方針を決める |
| 8 | 連続計算・回帰・引継ぎ | 静止/並進/回転の等方障害物から開始し、その後に採用した非等方条件。基準落下・境界・応力・初期化を再確認 |

C-2を直したら、run.pyの `sphere-known-C2-detected` を「失敗できたら合格」のまま残さない。
正常系の有限性・分布・半径・再現性へ更新し、旧不具合の検出は必要なら試験内の対照例として分離する。
修正後のチェック数が92と同じことより、判定内容を追跡できることを優先する。
probeは元ソース変更後に新規出力先で再ビルドする。抽出目印が変われば内容を確認して追従する。

既存コマンドと採用したdt付近の連続試験は工程2記録を参照。
`stage2.py`の既定引数は旧dt=.001を含むため、終了コード1だけで新しい不具合と断定しない。
`summarize_stage2.py`は過去にコンパイルしたGLSLと現在の実行文の一致を要求する。
工程3で式を変えた場合、旧結果と新結果の不一致を無視して同じ結果群に混ぜず、変更後の連続試験を取り直す。

## 判断が必要な箇所と完了条件

以下は候補であり、本書で方式を決定・承認したものではない。

- 球配置: 既存の半径解釈を維持する範囲と、領域・体積/質量を整合させる変更を分ける。
- 非等方SDF: 近似の継続、距離評価方法の変更、支持する変換の制限を、誤差とSwingへの影響から比較する。
- 符号: 対応する閉曲面・面方向などの前提を定め、擬似法線等の候補を既知形状で比較する。
- 退化/反転: 検知して停止する、以前の状態を保持する、正則化・対応SVDを採用する等を比較する。
  試験ツールの異常停止と、本体が異常時に採る仕様を区別する。NaNを0へ置換しただけで物理解決とはしない。

退化/反転はP2G入力とG2P射影前 `(I+dt C_new)F_old` でも記録し、
射影後の保存Fが有限という理由で途中の異常を隠さない。
研究結果の意味を変える仕様選択は、具体的な比較結果を準備してから利用者に確認する。
通常の再現試験・独立参照解の準備・明確な不整合の最小修正で毎回確認を増やさない。

完了時にはB-6a〜e/C-2/C-9ごとに、採用方式・誤差・対応入力・非対応入力・異常時の扱いと理由を記録する。
実GPUの関連試験と工程2回帰に合格し、未実施の統合操作は理由と残件を明示する。
PLANS、台帳、対象コメントを同時に更新してから工程4へ進む。
