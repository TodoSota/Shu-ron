## 試験と事前許容誤差

許容誤差は `run.py` のTOLでGPU実行前に固定し、結果に合わせて緩めていない。
最初に実行した版からSVD・転送・応力・初期化の閾値を保持した。

| 対象 | 実行対象と独立した期待値 | 判定 |
|---|---|---|
| SVD | 現在のP2G/G2Pから関数を抽出してGPU実行。単位・対角・回転・せん断＋seed=0のI+0.1N乱数128個。NumPy SVDと比較 | 再構成、U/V直交性、対角化、特異値の誤差≤5e-4 |
| 退化/反転 | diag(1,1,1e-5)、diag(1,1,-1) | 有限性を確認。直交性やdetUを診断記録し、材料の正常系合格には含めない |
| 応力 | P2GのSVD・応力計算部を抽出。F=I、回転、既知伸縮、回転付き伸縮、せん断。独立解はB=FFᵀのeighからlogストレッチを計算 | 応力誤差/ max(E,期待応力ノルム)≤5e-4 |
| 塑性/硬化 | G2Pの材料更新部をそのまま実行し、C=v=0で分離。単位、等方圧縮/引張、純せん断、弾性圧縮。NumPy SVDから独立に射影 | F誤差≤5e-4、q/alpha/vc≤2e-6、state一致 |
| P2G | 本体シェーダー全体を無変更で実行。定数・アフィン・剛体回転。節点ごとの区分的中心Bスプライン参照解と比較 | 質量総和の相対誤差≤3e-6、節点質量/運動量、全運動量/角運動量の相対誤差≤3e-5 |
| G2P | 本体シェーダー全体を無変更で実行。解析的格子速度場、全節点質量1を入力 | v=b+Ax、C=Aに対し誤差≤3e-5、有限性、q=0でのalpha連続性≤2e-6 |
| 初期化 | 本体resetParticlesの関数本体を抽出したC++を実GLバッファ上で実行。周囲の所有者/評価クリアだけを最小代替 | 立方体有限性/範囲、v=C=0、F=I、state=1、q=vc=0、alpha、両バッファ一致、再初期化再現性 |
| 初期物理値 | main.cppの定数・起動時集成初期化・resetMpmSimParamを抽出しC++実行 | 体積総和0.027、質量総和10.8、再設定一致、半径dx/2。相対/絶対誤差≤2e-6 |

通常の行列/ベクトル比較は `||actual-expected||F/max(1,||expected||F)`。
SVDの直交性はIとの比較、対角化は `||offdiag(VᵀFᵀFV)||F`。
P2G保存量・節点分布は期待値のノルムで正規化する。角運動量にはAPICの粒子内成分
`m dx²/4 axial(C−Cᵀ)` を含める。GPUの加算順についてビット一致を要求しない。
同じCPU処理の再初期化とバッファコピーだけはバイト一致で確認する。

## 試験整備中の失敗と制約

### 試験用プログラムで修正したこと

本体は普段起動する砂のシミュレーター、試験用プログラムは今回追加した検査用の道具を指す。
以下の設定追加・修正は試験側ですでに実施済みであり、本体への追加作業の依頼ではない。

| 起きたこと | 対応と本体との関係 |
|---|---|
| 最初の試験で格子への転送結果がゼロになった | 試験側でテクスチャのmin filter設定を付け忘れていたため、NEARESTを指定。本体の `src/mpm/3dtexture/MpmObject3DTEX.cpp` にはもともと同設定がある。 |
| 結果をJSONファイルへ保存できなかった | NumPyの真偽値を保存できる型へ変換。試験側の結果保存処理を修正した。 |
| 初期化probeをビルドできず、途中版にはライブラリ競合警告も出た | 試験用のビルドを/MD＋dynamic GLEWへ調整し、最終版は警告・エラー0。本体のvcxprojは変更していない。 |

最初の `stage1-20261116-a` や初期化probeの途中ディレクトリは、最終の成功証跡として使用しない。
本体のRelease文字化け・文字コード設定の差は、これらとは別の未解決事項として工程0の記録に残る。

### 今回確認できた範囲

抽出対象のアンカーが変われば停止する。GLSL/C++の生成物とハッシュを残すが、
アプリの全呼出し経路・資源所有・再起動UIの検証を代替するものではない。
ここでいうアンカーは「本体から計算部分を取り出す際の目印」、ハッシュは「ファイル内容を識別する値」である。
本体の変更後に、以前取り出した古い計算処理を誤って試験しないために使う。

今回の試験では、計算の各部分を個別に確認した。例えばG2Pには正解が分かっている格子速度を与えた。
Setup → P2G → Grid → G2Pをつなげて何度も進め、砂全体が安定して動くかを確認した試験ではない。
初期化も、実際の初期化関数とGPU上の粒子データを調べたもので、再起動UIを含むアプリ全体の確認ではない。
既存CSV/評価そのものの検証はR-1で残る。

境界・SDF・落下/堆積・dt半減・長時間・大量粒子・SSBO/線形・Win32・RTX 4060は未実施。
